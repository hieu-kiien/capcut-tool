# CapCut Tool Docs

Thu muc nay chi nen dong vai tro nhu bo nho ngan gon cho AI. Khong can doc tat ca file Markdown trong moi lan lam viec.

## Nen doc truoc

1. `PROJECT_CONTEXT.md` - tom tat muc tieu, module chinh, trang thai hien tai, lenh kiem tra.
2. `REVIEW_STATUS_CURRENT.md` - cac muc ky thuat da xac minh va viec con mo.
3. `MVP_SPEC.md` - doc khi thay doi pham vi san pham, UI flow, hoac backend pipeline.

## Tai lieu tham khao dang hoat dong

- `OPEN_SOURCE_DECISIONS.md`: quyet dinh ve repo tham khao ben ngoai va tich hop khong lam.
- `QUY_TRINH_VA_PHAN_BO_THOI_GIAN.md`: SOP san xuat video va phan bo thoi gian noi dung.

## Archive

`docs/archive/` chua handoff, backlog, review task va test note cu. Chi doc khi can truy vet lich su, khong dung cac file nay lam trang thai hien tai.

Da archive:

- `HANDOFF_LONG_STORY_CAPCUT.md`
- `REVIEW_FIX_TASKS.md`
- `REVIEW_REMAINING_TASKS.md`

## Ghi chu cho AI

- Giu `AGENTS.md` o thu muc goc de Codex tu nhan quy tac lam viec.
- Neu can ngu canh nhanh, doc `PROJECT_CONTEXT.md` truoc khi dung `rg`.
- Khi can tim source, bat dau tu cac file duoc neu trong `PROJECT_CONTEXT.md` thay vi quet toan repo.
- Khong can build/package tru khi user can EXE hoac artifact phan phoi.
